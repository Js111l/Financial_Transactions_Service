## General Info  
This repository contains the code for Financial Transactions Service - one of the core microservices of **Shopiqo**, a full-stack e-commerce platform. 
The  Financial Transactions Service is developed using Scala, Akka HTTP and Guice. Service is responsible for handling payments and management of user orders. 
Service is integrated with Stripe API.
